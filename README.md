# 制物 Studio

给画师与制品设计者使用的本地 3D 样机工作台：查看吧唧、纸品和亚克力在不同底材、印刷层、工艺与灯光下的效果。项目采用 React、TypeScript、Three.js 和 IndexedDB，按纯离线 PWA 设计，无需账户。

## 产品范围

v1 已实现以下完整流程，通过21项单元测试和15项生产构建端到端测试。详细证据与已知限制记录在 [持续进度](docs/PROGRESS.md)。

- 三类样机：带包边与背针的圆形吧唧、纸品，以及透明/磨砂/白色亚克力；按制品选择底材、尺寸、厚度和形状。
- 一次导入多张 PNG、JPEG、WebP 或安全 SVG，逐张分配给正背面印刷、白墨、光油、磨砂、烫色、纸品压凸/压凹，或只存入素材库。
- 工艺蒙版支持透明度与灰度解释、反相和阈值；调整图层位置、比例、旋转与显示状态，保留原始图片。
- 切换场景预设、灯光方向与强度，拖动查看三维效果；下载当前视角的 PNG 效果图。
- 自动保存到本机项目库，撤销/重做；下载包含原图的工程备份，并导入为新的项目副本。
- 内置形状与受限的单闭合 SVG 刀线；结合当前材料和工艺提供制作提醒。

PSD 分层、PDF/AI/EPS、TIFF、多轮廓刀线、独立立牌装配和生产级分色文件不在 v1 范围内。详见 [产品规划](docs/PLAN.md)。

## 本地启动

使用项目 `.node-version` 指定的 Node.js 24 与 npm。首次安装依赖需要网络；应用运行不应依赖外部图片、字体或服务。

```bash
fnm install
fnm use
npm install
npm run dev
```

打开终端显示的本地地址。开发服务用于编辑代码，离线验收请使用生产构建：

```bash
npm run check
npm test
npm run build
npm run preview -- --port 4173
```

在浏览器中打开 `http://localhost:4173`。直接双击 `dist/index.html` 不能替代本地服务，Service Worker 需要 localhost 或 HTTPS 环境。

端到端测试命令如下；首次配置测试浏览器需要网络：

```bash
npx playwright install chromium
npm run test:e2e
```

这些是项目命令，执行结果以实际输出及 [验证记录](docs/PROGRESS.md) 为准。

## Cloudflare Pages

仓库已提供 Wrangler 配置与 Pages 构建、预览和发布命令；尚未实际发布到 Cloudflare。推荐在 Pages 连接本仓库的 `main` 分支，构建命令使用 `npm run build`，输出目录使用 `dist`，Node.js 版本由 `.node-version` 指定。

本地检查 Pages 静态服务：

```bash
npm run pages:dev
```

GitHub 集成、Wrangler 登录与手动发布步骤见 [部署指南](docs/DEPLOYMENT.md)。托管仅分发应用文件，图片和工程仍保存在用户设备内。

## 离线使用

1. 启动生产预览服务并打开 `http://localhost:4173`，等待应用明确提示可离线使用。
2. 按浏览器提供的安装入口安装 PWA；未提供安装入口时仍可使用浏览器页面。
3. 首次缓存完成后，在同一浏览器与相同地址重开应用，检查断网刷新、编辑和保存均可使用。安装完成与缓存完成不是同一个状态。

图片、工程与预览处理都留在设备内。已用生产构建验证：初次缓存完成后，断网刷新、关闭页面后重开、继续编辑保存和导出都能工作。首次获取应用仍需要本地服务或HTTPS；浏览器必须保留此站点缓存。

本机项目与浏览器、浏览器配置及地址有关。例如更换端口、改用 `127.0.0.1` 或清理站点数据后，原地址下的项目不会自动出现在新地址中。重要项目请额外下载备份。

## 保存、备份与恢复

编辑后观察顶部保存状态：只有“已保存在本机”表示写入成功。保存失败时保留当前页面和编辑内容，使用重试；需要离开前先下载项目备份，不把一次点击当作已保存。

使用工作台的备份操作下载完整工程，包含项目设置及原始图片。恢复时在项目库选择导入备份；有效备份应生成新副本，保留当前项目。图片缩略图与 PNG 效果图不能替代工程备份。

备份损坏或版本不受支持时应保留原文件并按提示处理，不要手动删除原工程。浏览器清理站点数据、设备更换和私密浏览会影响本机存储；跨设备迁移请使用工程备份。

## 真实制作边界

本应用用于检查结构、图案分布、材质与工艺关系，效果图不是生产合格证明。颜色、反光、压纹细节与实际触感以实物打样为准。

不同厂商的出血、留边、最小线宽及工艺组合存在差异。灰度蒙版也不自动意味着生产设备支持连续深浅：白墨与部分工艺按二值区域加工。通用预览会区分明确不兼容、制作提醒和需厂家确认的项目，不使用未经确认的统一行业阈值。依据见 [制造调研](docs/manufacturing-research.md)。
