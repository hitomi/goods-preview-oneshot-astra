# 制物 Studio · 产品规划

## 目标与完成边界

面向独立画师、同人制品设计者和小型工作室，制作一个无需账户、素材不离开设备的离线 PWA。在真实三维样机上检查图案、底材、局部工艺和不同照明下的效果，减少送厂前发现设计问题的成本。

本轮交付是可运行、可测试、可继续扩展的 v1，而不是静态演示。必须完成三种制品、批量导入和逐图用途分配、灰度/Alpha 工艺蒙版、多层管理、制作约束、场景调整、本地保存恢复、备份导入导出、PNG 效果图与离线冷启动验证。不能把“理论上支持所有工厂、所有工艺”作为完成标准。具体工厂规范和打样仍是生产依据。

## 使用流程

1. 首次直接进入带内置设计的样机工作台，能立即拖动观察材质；无需先建立空项目。
2. 选择吧唧、纸品或亚克力及常用尺寸；选择该制品实际适用的底纸、板材或覆膜。
3. 一次拖入/选择多张 PNG、JPEG、WebP、SVG。导入表逐张指定正/反面印刷、白墨或某种工艺蒙版，也能仅存入素材库。文件名只建议用途，用户最终确认。
4. 工艺图明确选择 Alpha 或灰度、反相和阈值，预览有效区域；印刷图保留彩色。错误文件独立报告，可继续处理其他有效文件。原图永远保留。
5. 按制品层序预览；调整图案位置、比例和旋转，启用/隐藏工艺，查看刀线和尺寸，检查材料兼容性。
6. 切换柔光棚、暖光桌面、暗色展台和日光等预设；调整光方向、强度、环境光与背景，查看正反面并导出当前视角 PNG。
7. 自动保存到本机项目库。刷新/离线重开恢复；可下载包含原图的独立项目备份，并导入为新副本。

## 制作边界

- 规则分为“不能使用”“需要注意”“需与厂家确认”。技术解析失败与明确结构不兼容才硬阻止；未验证的经验数值不能伪装成统一标准。
- 吧唧覆膜单选；底纸效果不等于任意局部金属工艺。亚克力不支持纸张压凹凸。保留切换类型前的素材，避免静默删除。
- 局部工艺蒙版默认二值加工区域，阈值可调；画面上的强度是视觉近似，不能代表可连续调节的生产工艺。
- 提供像素密度、出血/安全区、白墨/透色、特殊材质及复杂刀线提示；精确出血、套印误差、最小线宽由厂商模板决定。
- 效果图明确是视觉参考，不输出伪造的印厂合格证明或生产级刀模文件。

## 里程碑与验收

1. M0 文档与技术契约：范围、流程、结构、制造来源和持续进度写入仓库。
2. M1 本地数据闭环：项目、素材、兼容规则、蒙版解读、保存失败恢复、备份与导入校验。
3. M2 工作台与三维：三类可辨识实体、多层局部工艺、材质/尺寸/图案操作、真实相机和场景。
4. M3 完整工作流：批量分配、素材复用、撤销/重做、自定义刀线、制作检查、项目库与导出。
5. M4 离线与验证：生产构建无外链依赖；断网刷新并编辑保存；多桌面宽度及移动布局；键盘与导入失败；测试及截图留证。

验收需运行应用和 Playwright；构建成功不能单独证明三维效果、离线或保存流程。性能以按需停止帧、纹理预算、资源释放、实际测量为证据，不预先许诺设备无关的帧率。
