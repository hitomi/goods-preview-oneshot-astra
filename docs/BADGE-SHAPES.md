# 吧唧结构与多形状预览

2026-09-05 用户追加：让吧唧结构更接近实物，并支持圆形之外的常见形状。

## 用户操作与范围

选择吧唧后，先选圆形、椭圆形、圆角方形、圆角长方形、心形或星形，再选对应的尺寸示例。形状切换使用该形状默认尺寸，保留原图、所有图层与工艺设置，并可撤销。圆形、圆角方形、星形绑定宽高；其他形状可调整宽高，椭圆和长方形提供横竖预设。

尺寸表示成品外轮廓，包含弧肩在正投影中的范围。图案按成品宽高放置，转弯处会沿肩部与包边显示；正面安全区域更小，预览并不生成厂家展开裁纸模板。不同工厂的外形曲率、包边宽度与背针结构会不同。

不将任意图片刀线应用到冲压包边吧唧：它需要匹配前盖、背盖与模具。纸品与亚克力的自定义刀线能力保持原有范围。切到吧唧时已有刀线、原图和不兼容图层保留，以便撤销或切回。

## 建模与性能决策

- 前盖使用连续的浅鼓面、圆肩、短侧壁和内卷边，图案在同一网格上连续映射。按径向弧长模拟包边展开，再统一缩放画布以保持中央图案比例；这是通用映射，不能代替厂家裁纸展开图。
- 背盖跟随外形内缩，形成内凹冲压盘和台阶，不再用相互覆盖的平圆盘模拟。
- 安全针包含线材弹簧、固定杆、活动针和卡扣，按可用内部宽度缩放。
- 心形凹口、星形凹角和矩形角保留圆角，减少不符合冲压结构的尖锐边缘。
- 所有形状共享有界网格生成；仍按需绘制、按画质限制分段与纹理，切换时释放GPU资源。非正方形按真实宽高合成纹理。
- 不改项目版本，不引入依赖，不新增运行时网络请求。裁剪范围继续按完整模型视向包围盒更新，保留之前深度冲突修复。接影平面放到该包围盒的最远视向深度后方，避免倾斜时穿进模型；画布与PNG导出复用定位。
