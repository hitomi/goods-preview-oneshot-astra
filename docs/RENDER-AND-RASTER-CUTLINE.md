# 渲染修正与图片刀线（2026-09-05）

## 用户可见目标

修正截图中的吧唧金属背面斑纹、70×210mm薄纸正面斜向遮挡；通过真实浏览器与几何/深度证据确认原因，覆盖三类制品的正背面，保留现有透明亚克力印刷层关系。

刀线导入沿用批量分配工作流。PNG/JPEG/WebP线稿可指定为“制品刀线”，在原图上检查识别出的矢量轮廓；支持自动识别红线或黑线，并可手选线色。现有SVG导入继续可用。只有一个闭合外轮廓可应用到纸品或亚克力，吧唧保持实际圆形结构。

## 识别与保存边界

- 位图解码复用最大2048px预览，原图完整留在素材库和工程备份。识别算法在本地Worker执行，关闭或换参数时取消旧任务，避免卡住页面或应用过时结果。
- 沿线条内缘追踪、简化为单闭合矢量轮廓；保留凹口，不使用凸包，不静默补齐断口。线宽和图像分辨率会引入误差，应用前展示轮廓叠加与实际制品尺寸，可下载SVG检查。
- 拒绝开口、多轮廓、孔洞、不可识别和过于复杂的图片，说明如何修正；识别失败或保存失败均保留这批图片和用途。
- 保存时同时提交原图与生成SVG；轮廓走现有SVG几何验证，工程格式继续使用版本1的cutline字段。撤销、刷新恢复、备份回导均沿用现有事务边界。
- 生成刀线以制品宽高缩放，预览明确显示当前尺寸与比例差异，避免把图片像素误当制造毫米。结果用于样机；送厂仍需核对线宽误差及厂家刀模要求。

## 验收

1. 两张截图对应的渲染复现与修正后截图，覆盖长矩形薄纸和吧唧背面。
2. 红线、黑线、透明背景、JPEG抗锯齿、凹形轮廓；开口、多轮廓、自交、纯色图拒绝。
3. 批量混合印刷图/刀线图，预览识别，导入后外形切换、刷新恢复、撤销保留原图、SVG下载、备份回导。
4. 失败保留输入、切换识别颜色不使用旧结果、取消识别可关闭；离线状态仍能启动Worker。
5. 类型检查、领域单测、生产构建、相关Playwright，再检查实际变更范围与文档一致性。
