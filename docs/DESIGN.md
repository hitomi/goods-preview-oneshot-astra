# 交互与视觉设计

## 设计原则

预览始终居中，选择按制作顺序展开。用户操作的是“底纸”“图案”“烫金区域”“灯光”，不是纹理通道、shader 或数据库记录。默认参数应立刻得到完整样机。

采用安静、精确的浅色创作工作台：暖白背景、石墨文字、深松绿主操作、小面积橙色制作提示。24px 主留白、清晰分组、细边框；画面不放宣传语和假统计。中文使用本机系统字体，无运行时字体请求。

## 信息架构

- `/studio/$projectId`：顶部项目名/保存状态/项目库/备份/导出；左侧制品及图层；中央三维画布和视角工具；右侧当前图层或场景属性。底部场景预设是可操作的画面缩略选择。
- `/projects`：本机项目缩略、名称、更新时间；新建三类项目、导入备份、重开项目。不存在的项目显示恢复入口，不能混同为空白项目。
- 弹窗用于批量导入分配、增加工艺和帮助。未提交的导入内容不因点遮罩/Escape 丢失；显式取消才释放临时素材。
- 窄屏保持三维可见，设置以有标签的分页面板切换；不把三栏压缩到不可操作。

## 导入分配

显示缩略图、文件名、尺寸、用途、蒙版解释。识别文件名中的 print/正面、back/背面、white/白墨、foil/烫金、uv/光油等作为建议。Alpha/灰度取样只影响建议，最终有持续可见的选择器。一个素材可多次用于不同层。批次先处理再统一提交，写入成功后才关闭。

刀线图片沿用批量分配：纸品/亚克力每批最多一张选为刀线；独立刀线入口会为第一张图片预选用途。选择后显示原图与矢量线叠加，可自动识别或手选红线/黑线，放大核对并下载SVG。识别未完成时不能提交；错误、切换颜色和取消不会应用旧结果，也不会清空其他待导入图片。显示线条内缘误差及成品宽高，比例不一致时明确说明会拉伸。手机上完整显示整条轮廓，详细核对使用独立可滚动视图。

## 反馈与恢复

- 自动保存：“正在保存”“已保存在本机”“保存失败 · 重试”。事务失败保留内存编辑，仍可下载备份。
- 撤销/重做包括制品参数、图层、场景；不撤销已导入原图，防止失去恢复能力。
- 重新选择产品时保留素材与原有图层；不兼容工艺不参与渲染且明确提示，可切回恢复。
- 制作检查直接指出是哪一层、原因、用户可采取的行动。来源与局限在帮助文档说明。
- 只在缓存完成后显示“可离线使用”；安装能力由浏览器决定，不能假装已安装。
- 降低动态效果时不自动旋转；默认不持续旋转，节省电量。鼠标拖动与触摸操作提供可见提示和按钮替代。

## 视觉验收

1440/1920/2560/3840px 为一级桌面目标；面板宽度可受控，画布自然扩展。另验证 390px 触摸布局。所有图标按钮有名称，表单有持久标签，可见键盘焦点。选中态同时使用文字/轮廓，而非只依赖颜色。
