# v1 风险驱动验收计划

基线：[PLAN](PLAN.md)、[DESIGN](DESIGN.md)、[ARCHITECTURE](ARCHITECTURE.md)。本文规定如何验收，不是测试通过记录。实际命令、结果、截图路径与未覆盖项写入 [PROGRESS](PROGRESS.md)。

## 通过标准与环境

- 以生产构建完成主要 Playwright 流程，另运行 `npm run check`、`npm test`、`npm run build`。开发服务器成功不能证明离线可用。
- 使用隔离浏览器上下文；记录操作系统、浏览器版本、视口、DPR 和渲染器。原有用户项目不得作为破坏性测试数据。
- 断言以用户可见结果及持久化后重开为主；保存事务延迟/失败、资源释放等另用测试夹具或受控注入。等待状态变化，不依赖固定延时。
- P0 表示数据完整性、离线闭环或主路径不可用，任何失败均阻止 v1 完成；P1 表示核心效果、输入恢复与可访问性，必须验证或明确修复/限制；P2 为增强覆盖。
- 截图证明视觉状态，不能单独证明文件包含原图、写入成功、无网络依赖或键盘可用。每个失败须记录复现步骤与保留数据情况。

## 固定素材夹具

准备可重复使用的小型图像，不依赖线上素材：

| 夹具 | 要验证的差异 |
| --- | --- |
| 彩印 `front.png` 与带文字 `back.png` | 四角颜色/方向标记不同，检测翻转、裁切、正背面映射 |
| 全不透明灰度阶梯 | 黑、灰、白区域，检测灰度与 alpha 不可混用 |
| alpha 阶梯图 | 相同 RGB，alpha 为 0/低值/中值/255，检测覆盖区域 |
| 透明底隐藏 RGB 图 | alpha 为零但 RGB 为白，检测透明内容不会意外激活工艺 |
| 同一画布不同透明边距的正背/工艺图 | 检测自动裁切后图层错位 |
| 大尺寸图与已知原始字节 | 检查预览缩小，原图尺寸和字节仍保留 |
| 伪装图片、损坏 PNG、不受支持文件 | 批量部分失败与解码失败恢复 |
| 合法单闭合 SVG；开放/自交/多个轮廓/外链 SVG | 刀线几何校验和本地资源边界 |
| 有效工程、截断 JSON、未来版本、缺资产、外部 URL 工程 | 备份导入接受与拒绝路径 |

## M1 数据与输入验收

| ID / 优先级 | 路径与操作 | 必须观察的结果 | 验证方式 |
| --- | --- | --- | --- |
| D01 / P0 | 新项目调整尺寸、改名、加图层；等待已保存；刷新、进入项目库再重开 | 名称、尺寸、图层、素材和场景一致；已保存状态晚于事务完成 | Playwright + IndexedDB 事务单测 |
| D02 / P0 | 延迟第一次保存并连续修改两次，再释放保存队列 | 最终重开是最后编辑版本，旧写入不会覆盖新状态；保存中不提前报成功 | 单测为主 + 受控端到端 |
| D03 / P0 | 注入一次存储写入失败；编辑后点重试，再刷新 | 明确显示失败且输入保留；重试成功才显示已保存；重开为编辑后版本 | 单测 + Playwright |
| D04 / P0 | 持续保存失败时尝试去项目库；下载当前项目备份 | 不静默离开丢编辑；备份包含当前未持久化设置及所需素材；用户可继续编辑 | Playwright |
| D05 / P0 | 批量导入 3 张有效图与 2 张错文件；逐图分配不同用途并确认 | 单文件错误说明可见，其他图可继续；有效图均有对应图层或素材，零静默覆盖/截断 | Playwright |
| D06 / P1 | 导入多张同用途图；文件名建议用途与用户手选不同；复用同一素材 | 用户选择生效；每张映射可辨识；同素材能用于多个层，不替换原层 | Playwright |
| D07 / P0 | 灰度阶梯选灰度，改变阈值并反相；alpha 阶梯选透明度，执行同样操作 | 遮罩预览和三维结果对应约定；阈值边界一致；全不透明灰度图不会被错误自动确认成整面工艺 | 单测 + Playwright 截图 |
| D08 / P1 | 在透明底隐藏 RGB 图上切换解释、反相与阈值 | 完全透明像素不因隐藏 RGB 激活；无半透明区时 UI 不伪称存在 alpha 渐变 | 蒙版像素级单测 |
| D09 / P1 | 在分配弹窗已选用途后点击遮罩、按 Escape、Tab；显式取消；再导入 | 未提交内容不因意外操作丢失；取消没有新增资产/层；重新导入正常；焦点返回触发入口 | Playwright 键盘与指针 |
| D10 / P0 | 大图导入并备份，回导后比较原图；检查预览尺寸 | 预览受预算限制；原图字节/尺寸仍等于夹具；超限内容明确拒绝，不悄悄降成原图 | 单测 + 文件比对 |
| D11 / P0 | 下载工程；另改当前项目后回导刚下载文件 | 导入产生新 ID/副本，原项目及后续修改保留；新副本含原图、图层参数和场景 | Playwright + 备份单测 |
| D12 / P0 | 逐个导入截断、未来版本、非法尺寸、缺资产、外链及超限工程 | 不写入半个项目；清楚说明不能导入；当前项目和库不变；之后有效工程仍能导入 | 单测 + Playwright |
| D13 / P0 | 项目 A 编辑后打开 B，编辑 B，再返回 A；打开不存在的项目 URL | 两项目资产与设置不串；A 保存未完成时受保护；不存在项目显示恢复入口，不生成假空项目 | Playwright |
| D14 / P1 | 图层变换、灯光与制品类型修改后连续撤销/重做，再刷新 | 顺序符合编辑历史；原图仍在素材库；最终状态可保存重开；无意外新建资产 | 单测 + Playwright |

## M2/M3 三维与工作流验收

| ID / 优先级 | 路径与操作 | 必须观察的结果 | 验证方式 |
| --- | --- | --- | --- |
| R01 / P0 | 依次查看吧唧、纸品、亚克力的正面、背面与侧面 | 可辨识真实厚度/边缘；吧唧有弧面与背针；纸品不是悬浮贴图；透明亚克力能看到透明关系 | Playwright 截图 + 人工判断 |
| R02 / P1 | 导入四角彩色正背图，改变尺寸/比例/位置/旋转；翻到背面 | 方向及文字可读；同画布图层对齐，透明边不被独立裁掉；重开保持变换 | Playwright |
| R03 / P0 | 纸品添加压凸/压凹与彩印后切亚克力，再切回纸品 | 亚克力不渲染不兼容压印，说明可见；图层与原图保留，切回能恢复 | 兼容矩阵单测 + Playwright |
| R04 / P1 | 透明亚克力分别选无白墨、全白/按图案白墨、自定义白墨；旋转并换背景 | 白墨实际改变指定区域的遮盖，未覆盖处透色；只调整全模型透明度不能算通过 | Playwright 截图 + 人工判断 |
| R05 / P1 | 使用局部二值蒙版分别加光油、哑油和箔色；旋转光源及样机 | 工艺仅出现在有效区域；光油/哑油反光不同；箔会遮盖底图并产生金属反射 | Playwright 截图 + 人工判断 |
| R06 / P1 | 纸品压凸/压凹相同区域；切侧光、翻背面和降低强度 | 凸与凹方向可分；强度不会生成越界/穿透几何；不能仅用不变颜色假装凹凸 | Playwright 截图 + 人工判断 |
| R07 / P1 | 切换所有底材与覆膜；检查可选工艺及制作提示 | 制品选项相关；吧唧亮/哑膜互斥；未实现或不兼容能力不能伪装可用 | 目录单测 + Playwright |
| R08 / P0 | 导入有效单轮廓刀线，切换内置形状再恢复；尝试非法 SVG | 有效轮廓改变实体轮廓且可重开；非法输入不造成白屏/远程请求，旧形状保留 | 几何单测 + Playwright |
| R09 / P1 | 故意低像素密度、重要内容近边、透明材质缺白墨 | 提示与当前项目相关，说明影响和可采取操作；仅已实现的检查被称为已检查 | 单测 + Playwright |
| R10 / P0 | 选场景并旋转至明显非默认角度，导出 PNG；打开下载文件 | 有效 PNG、尺寸合理、内容非空；视角/灯光与画布一致；没有不期望的 UI；失败不会显示成功 | Playwright 下载 + 图像检查 |
| R11 / P1 | 四个预设间切换后手动改光方向、强度、背景，再保存重开 | 每个预设有可观察变化；手调及时生效，状态和画面一致；不重新解码全部原图 | Playwright + 性能观测 |

## 性能与资源证据

不预设设备无关的帧率保证。至少记录以下实际观测：

| ID / 优先级 | 操作 | 期望与证据 |
| --- | --- | --- |
| P01 / P1 | 静置画布；拖动停止；隐藏标签页 | 按需绘制停止，阻尼结束后不持续渲染；隐藏时停止动画。记录帧调用计数或等价证据 |
| P02 / P1 | 反复换项目、图层图像、材质与刀线 20 次 | geometry/texture/object URL 不持续线性增长；记录资源计数趋势，排除浏览器延迟回收后再判断 |
| P03 / P1 | 导入代表性批次并调灯光/图层 | UI 不因无界并发解码长期失去响应；显示处理状态；纹理受质量预算限制；原图未损失 |
| P04 / P2 | 低/标准/高质量切换，调整 DPR 与窗口大小 | 绘制尺寸符合质量预算；仍能访问全部有效图层/素材；不通过隐藏数据改善性能 |

验收完成前复核浏览器控制台未处理异常与 WebGL 错误。若缺少 GPU、无法安装浏览器或故障注入尚未覆盖，必须记录具体未验证路径和剩余风险；不能以类型检查或构建通过替代。

## Cloudflare Pages

`npm run test:pages` 构建后通过 Wrangler 本地服务运行全部应用端到端测试，并追加 `tests/pages/hosting.ts`：直接请求项目库与工作台深层地址应返回应用 HTML；入口、Service Worker 与清单必须重新验证；哈希资源使用长期缓存。离线检查根据当前测试服务的 origin 判断外部请求，使 Vite 和 Pages 两种环境保持同一约束。

该命令不创建或发布站点。真实 Pages 部署后，仍需在最终 HTTPS 域名复核路由、首次缓存及离线冷启动；步骤见 [DEPLOYMENT](DEPLOYMENT.md)。
