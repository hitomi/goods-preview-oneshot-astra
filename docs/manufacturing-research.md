# 制造约束与预览边界

调研日期：2026-09-05。本文为首版产品与实现决策提供依据；以下是厂商公开资料中的实例，不构成通用生产标准。离线应用内置规则应记录版本和来源，不能把一次查阅的产品参数永久当作行业标准。

## 核心结论

应用应围绕「制品结构 → 底材 → 印刷 → 表面工艺 → 成形」组织能力，并区分三件事：能在屏幕上表现、有真实工艺实例、当前选定厂商能接单。没有选定厂商时，显示“通用预览 · 制作参数待确认”，不能给出“已通过生产认证”。

几何损坏、缺失图像、错误层类型可以准确校验。能否烫色、最细线宽、工艺叠加、出血距离等由设备、材料和供应商决定；应用默认提供保守的制作提醒及可解释的限制，不虚构统一阈值。

## 一手证据与产品含义

### 吧唧不是简单的平面金属圆片

Sticker Mule 的产品说明采用印刷纸、覆膜与镀锡钢背结构。Busy Beaver 则说明其出血区域会包到边缘/背部。因此正面可视区、包边区与下料边应分开，正面重要内容靠近包边需提示，圆形吧唧不能使用任意异形切边替换其成形模具。[Sticker Mule：Buttons](https://www.stickermule.com/support/faq/buttons)、[Busy Beaver：FAQ](https://www.busybeaver.net/faqs/)

Busy Beaver 的现成产品包括白纸、哑面、金属、镭射与珠光等方案；其哑面是覆膜工艺，镭射底材主要在浅色和留白区域显露。这支持“底纸”和“整面膜层”独立选择；不支持将任意吧唧底纸与所有局部工艺默认组合。[Busy Beaver：Special Finishes](https://www.busybeaver.net/special-finishes/)

### 纸品工艺需要独立区域，数值按供应商变化

MOO 的特殊工艺以独立黑白文件指定区域；箔会遮盖下面图案，光油改变局部光泽，其说明提醒细节与套准限制。这里的黑色是“施加工艺”，不是一个跨厂商通用的颜色约定。[MOO：Special Finishes design requirements](https://support.moo.com/hc/en-us/articles/206347686-Special-Finishes-design-requirements)

MOO 的特定 Spot Gloss 名片产品仅允许一种特殊工艺，采用指定纸张和哑面基底。这是套餐约束，不能据此断言全行业无法叠加工艺。[MOO：Spot Gloss Business Cards](https://support.moo.com/hc/en-gb/articles/48451616678036-Spot-Gloss-Business-Cards)

PrintNinja 的书封压凸/压凹说明要求独立实黑文件，并对材料、细节及距折叠区域的距离提出限制。本文不将书封的纸重或毫米值移植为所有纸品的统一门槛。预览只能表现凹凸方向和相对形态；真实压痕深度必须由纸张、模具和工艺确认。[PrintNinja：Emboss and Deboss File Setup Guide](https://printninja.com/emboss-deboss-setup-guide/)

### 亚克力必须明确白墨、印刷面和刀线关系

Zap 的透明亚克力教程包含正背彩印、白墨、光油和刀线层。无白墨的彩色区域会透色；其设备会把白墨/光油层中的低不透明度像素视为完整覆盖。其常规激光切割方案要求图案与刀线至少留 1 mm。因此“灰度 30%”不能自动等于“打印 30% 白墨”，且输入边缘的隐约像素需要让用户看清。[Zap：Clear acrylic artwork guide](https://zapcreatives.com/en-us/blogs/zap-blog/how-to-create-printed-clear-acrylic-keyrings-using-adobe-illustrator)

CORNER PRINTING 的 ACR-K07 产品要求刀线距设计 2.5 mm，并描述了不同单双面与光油方案的印刷层序。这与上面的 1 mm 案例不同，说明留边和层序均应属于具体制作档案。应用中用户按正常阅读方向上传正面/背面，渲染及导出再按明确的观察面处理镜像，避免要求用户猜测。[CORNER PRINTING：Acrylic Key Chain ACR-K07](https://www.cornerprinting.com/en/plain_products/ACR-K07)

Vograce 同时有满版亚克力和烫色亚克力产品。满版方案列出出血、间隙和细颈要求；烫色方案要求分离烫色区域并列出 0.2 mm 线宽/线距。由此不能把“亚克力必须永久留透明边”或“亚克力不能烫色”写成通用禁令，也不能将其 0.2 mm 参数直接用于纸张烫色。[Vograce：Full Bleed Acrylic Keychains](https://vograce.com/products/custom-full-bleed-acrylic-keychains)、[Vograce：Hot Stamping Acrylic Keychains](https://vograce.com/products/custom-hot-stamping-acrylic-keychains)

## 建议的首版兼容性矩阵

以下是本应用的实现策略，而不是厂商报价承诺。“可用”表示有合理结构及真实工艺依据；“条件可用”需要提示适用材料/工艺档案；“不开放”是当前建模范围不支持，不代表世界上不存在该工艺。

| 能力 | 吧唧 | 纸品 | 亚克力 |
| --- | --- | --- | --- |
| 全彩印刷 | 可用，正面加包边 | 可用，正背面分开 | 可用，区分单面/双面 |
| 普通白底 | 白色底纸 | 白卡/铜版纸等 | 白色板或白墨层；不可混为一物 |
| 特种底材 | 条件可用：镭射、珠光、金属效果底材 | 条件可用：色纸、纹理、珠光 | 可用：透明、乳白；有色/镭射条件可用 |
| 独立白墨 | 仅支持明确可印白的特种底纸方案 | 条件可用：深色/特殊纸与可印白设备 | 可用：全覆盖、按图案、自定义区域、无白墨 |
| 整面亮/哑处理 | 可用：表面膜层二选一 | 可用：覆膜/涂层二选一 | 可用：板材外观与印刷表面光泽分开 |
| 局部光油 | 条件可用：需厂家支持的表面结构 | 可用，提示纸张与底层表面适配 | 可用，作用面由印刷方案决定 |
| 局部磨砂 | 条件可用；不能冒充普通哑膜 | 条件可用，作为局部哑油 | 条件可用，区分哑油与板材表面处理 |
| 烫金/烫银/烫色 | 条件可用，需验证包边与膜层 | 可用，箔色为工艺而非彩墨 | 条件可用，采用支持烫色的制作方案 |
| 压凸/压凹 | 不开放普通纸面吧唧 | 条件可用，采用适合压印的纸张 | 不开放；不能以纸张压凸模拟亚克力雕刻 |
| 预设形状 | 受模具支持的圆/方等 | 方、圆角、圆等 | 方、圆角、圆等 |
| 自定义刀线 | 不开放普通冲压吧唧 | 可用，校验闭合轮廓 | 可用，校验细颈、尖角、孔边距离 |
| 挂孔 | 不适用普通吧唧正面 | 条件可用 | 可用，孔必须在有效板材内 |
| 满版印至切边 | 包边覆盖逻辑 | 可用，需预留出血 | 条件可用，单独启用满版制作方案 |

切换制品时，保留已上传源图与图层分配；不兼容工艺应禁用并解释原因，不能静默删除。再次切回时能恢复。

## 输入图像与工艺区域

下面是产品约定，应保存到工程文件以确保离线重开一致：

- 批量导入后逐图选择用途：正面印刷、背面印刷、白墨、光油、哑油、烫色、压凸/压凹、刀线参考、暂不使用。文件名识别仅提供建议，不自动确认用户意图。
- 工艺区域提供“透明度”“灰度（白色生效）”“灰度（黑色生效）”三种解释。预览遮罩叠色，并同时显示原图，避免默认把全不透明灰度图识别为整面工艺。
- 保留原图和非破坏性参数。明确提供反转、阈值；二值工艺以阈值后的结果渲染。若支持灰度强度预览，标记“连续强度仅供效果探索，需确认设备支持”。
- 透明像素的 RGB 隐藏值不应参与灰度区域计算；alpha 与亮度相乘。彩印的透明渐变与白墨的覆盖区域相互独立。
- 同一图片可复用到多个图层；多个图片对应同一用途时新增图层，禁止静默覆盖。图层需共享物理画布与对齐基准，不可分别裁掉透明边后拉满。
- 位图可作为刀线参考；只有成功提取并校验的闭合轮廓才能用于成形。未经处理的像素图不能被宣称为生产刀模文件。

## 校验分级

| 等级 | 适用情况 | 用户反馈与动作 |
| --- | --- | --- |
| 阻止当前操作 | 图像不能解码；尺寸非正数；轮廓未闭合/自交；挂孔越出板材；当前制品不支持所选结构 | 保留原输入；指出具体问题；只阻止受影响的应用操作 |
| 制作提醒 | 出血不足风险；重要图案可能进入吧唧包边；工艺接近边缘；复杂刀线/细颈；箔与其他表层重叠；灰度与二值工艺含义不一致 | 展示位置与原因；可调整或继续预览，不显示生产通过标记 |
| 效果提示 | 没有白墨而出现透色；浅色内容在深底上不明显；视角下未看到光油反光；双面图案不一致 | 给出解释与直接操作，如“查看白墨覆盖”“切换斜侧光” |
| 厂商特定规则 | 当前选择的厂商/产品档案明确要求线宽、出血、材料、工艺组合 | 显示档案名称、版本与来源；仅在该档案范围内判定不通过 |

如果实现只能检出部分问题，反馈必须写“已检查尺寸和工艺兼容性”，不能笼统写“可制作”。不能靠缩小预览图掩盖缺图、无效轮廓或分辨率问题。

## 可实现的渲染表现与明确边界

以下为设计/工程判断：

1. 真实几何用于厚度、吧唧弧面/包边、圆角、切边和孔；工艺分区用材质纹理表达。压凸/压凹采用受限的高度/法线表达，不把极大“强度”变成不可制作的雕塑。
2. 白墨改变透明基底上的遮盖关系；烫色改变金属反射和底图覆盖；局部光油/哑油改变粗糙度与涂层。不能仅用一张金色叠图或降低整件不透明度代替这些效果。
3. 提供中性检查光、柔光棚、侧光看工艺、暖色室内等本地预设；保留中性预设，避免用户只在夸张光照中判断图案。
4. 屏幕不可靠复现印刷色差、ICC 打样、实际墨厚、箔批次、纸张触感、细微套准偏差、镭射微结构、边缘热变形。界面用简短说明： “用于观察结构与工艺效果；颜色和细节以实物打样为准。”
5. 首版不承担工厂生产稿生成、报价、供应商自动匹配或结构强度认证。工程文件应包含源图、图层、尺寸、制作档案和版本，方便后续扩大能力，不把预览截图称为生产文件。

## 首版落地优先级

先做好三种制品的真实厚度与材质差异、批量图像分配、alpha/灰度区域解释、白墨、局部光油/哑油、箔色、纸品压纹、刀线与制作提醒，再增加材料花样。所有已开放工艺都应在旋转与换光后可观察；无法真实表达的控件先不开放。

若时间范围只能实现通用档案，保留来源文档、明确所有数值是预览默认值，并将“厂商规则配置”标为后续能力；不能展示一个尚未实现的认证流程。
